## Procyclidini Hydrochloridum: Rasmussen-Enzephalitis (Rasmussen subacute encephalitis)
{: .text-alpha }

### Zusammenfassung

Procyclidinhydrochlorid ist ein zentral wirkender Muskarin-Antagonist (Anticholinergikum). Für die Rasmussen-Enzephalitis (Rasmussen subacute encephalitis) liegt eine rein rechnerische Vorhersage vor. Diese stützt sich weder auf klinische Studien noch auf Literatur, daher ist die Evidenz sehr schwach (Niveau L5).

### Warum ist diese Vorhersage plausibel?

Procyclidin blockiert im zentralen Nervensystem Muskarinrezeptoren. Der Wirkmechanismus wurde für diesen Bericht nicht näher erfasst, daher ist keine vertiefte mechanistische Prüfung möglich.

Die Rasmussen-Enzephalitis ist eine immunvermittelte, einseitige Entzündung einer Hirnhälfte mit schwer behandelbarer Epilepsie. Die Erkrankung wird vor allem durch T-Zellen getrieben. Ein bekannter Zusammenhang zwischen Muskarin-Blockade und diesem Krankheitsprozess besteht nicht.

Der hohe Vorhersagewert beruht allein auf dem Rechenmodell. Aus den vorliegenden Daten lässt sich keine plausible biologische Begründung ableiten. Die Vorhersage ist daher als Hypothese zu verstehen, nicht als Hinweis auf eine Wirksamkeit.
