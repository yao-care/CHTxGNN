## Emtricitabinum: Felines erworbenes Immunschwächesyndrom (feline acquired immunodeficiency syndrome)
{: .text-alpha }

### Zusammenfassung

Emtricitabin ist ein antivirales Arzneimittel, das in der Schweiz als Kapselpräparat im Handel ist. Für das felines erworbenes Immunschwächesyndrom (feline acquired immunodeficiency syndrome) liegt ein sehr hoher TxGNN-Vorhersagewert vor, es handelt sich jedoch um eine Tiererkrankung. Die Evidenz stützt sich auf eine einzige veterinärmedizinische Publikation zu einer Kombinationstherapie; direkte klinische Studien fehlen, daher bleibt die Evidenz auf Modellvorhersageniveau (L5).

### Warum ist diese Vorhersage plausibel?

Emtricitabin gehört zu den nukleosidischen Reverse-Transkriptase-Hemmern: Es wird in die virale DNA eingebaut und bricht deren Verlängerung ab. Zum Wirkmechanismus liegen in den zusammengestellten Daten keine weiteren Angaben vor; die Aussage beruht auf der allgemein bekannten Wirkweise dieser Substanzklasse.

Das Feline Immundefizienzvirus (FIV) ist wie das humane Immundefizienzvirus ein Lentivirus mit einer verwandten Reverse Transkriptase. Ein Wirkprinzip, das gegen das eine Virus greift, könnte daher grundsätzlich auch beim anderen eine Rolle spielen.

Diese Plausibilität ist jedoch rein theoretisch. Die vorhandene Publikation untersucht eine Dreierkombination und keine Einzelsubstanz, und die Erkrankung betrifft Katzen. Für eine Anwendung beim Menschen ist sie nicht relevant.

### Fazit und nächste Schritte

**Entscheidung: Abwarten**

**Begründung:**
- Der hohe Vorhersagewert wird durch keine direkte klinische Studie gestützt; die einzige Publikation ist veterinärmedizinisch und betrifft eine Kombinationstherapie. Zudem ist die Erkrankung eine Tierkrankheit mit begrenzter Relevanz für die Umwidmung beim Menschen.

**Um fortzufahren, wird Folgendes benötigt:**
- Kontrollierte Studien zu Emtricitabin bei FIV-infizierten Katzen, idealerweise mit Einzelsubstanz-Auswertung
- Klärung, ob eine veterinärmedizinische Zielsetzung für dieses Vorhaben überhaupt vorgesehen ist
- Vollständige Sicherheitsangaben aus der Schweizer Fachinformation
- Angaben zum Wirkmechanismus aus einer verlässlichen Arzneimittelquelle
