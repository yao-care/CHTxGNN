## Dronedaronum: Schlaganfall (stroke disorder)
{: .text-alpha }

---

### Zusammenfassung

Dronedaron ist ein Antiarrhythmikum, das in der Schweiz unter dem Handelsnamen Multaq im Handel ist. Das Modell sagt voraus, dass es bei Schlaganfall (stroke disorder) wirksam sein könnte. Dieser Zusammenhang ist jedoch indirekt: Er läuft über das Vorhofflimmern, das ein wichtiger Risikofaktor für Schlaganfälle ist. Für eine direkte Wirkung von Dronedaron auf Schlaganfälle gibt es in den vorliegenden Daten keine Belege, das Evidenzniveau ist daher L5.

### Warum ist diese Vorhersage plausibel?

Zum Wirkmechanismus von Dronedaron liegen in den für diesen Bericht zusammengestellten Daten keine Angaben vor. Aus der Literatur ist bekannt, dass es ein Antiarrhythmikum mit Wirkung auf mehrere Ionenkanäle ist. Es hemmt zudem adrenerge Effekte, senkt die Herzfrequenz und den Blutdruck.

Schlaganfall ist eine der wichtigsten Folgekomplikationen des Vorhofflimmerns. Eine bessere Rhythmuskontrolle könnte theoretisch das Risiko für Embolien aus dem Herzen senken. Die ATHENA-Studie meldete eine Verringerung von Schlaganfällen als sekundären bzw. Post-hoc-Befund. Ein Nachweis, dass Dronedaron selbst Schlaganfälle verhindert, liegt nicht vor.

Der hohe Vorhersagewert spiegelt wahrscheinlich die Nähe von Vorhofflimmern und Schlaganfall im Modell wider und keinen direkten Effekt. Zudem ist Dronedaron bei permanentem Vorhofflimmern und bei dekompensierter Herzinsuffizienz kontraindiziert (PALLAS, ANDROMEDA). Das schränkt eine mögliche Anwendung zur Schlaganfallprävention deutlich ein.

### Fazit und nächste Schritte

**Entscheidung: Abwarten**

**Begründung:**
- Der Vorhersagewert ist hoch, es gibt aber keine Studie, die Schlaganfall als Zielerkrankung von Dronedaron direkt untersucht. Der Zusammenhang läuft nur indirekt über das Vorhofflimmern.
- Die Einschränkungen bei permanentem Vorhofflimmern und Herzinsuffizienz begrenzen eine mögliche Anwendung zusätzlich.

**Um fortzufahren, wird Folgendes benötigt:**
- Daten oder Studien, die den Effekt von Dronedaron auf Schlaganfälle als primäres Ziel untersuchen, zum Beispiel eine gezielte Auswertung der ATHENA-Daten.
- Die Warnhinweise und Kontraindikationen aus der Swissmedic-Fachinformation.
- Angaben zum Wirkmechanismus aus einer Arzneimitteldatenbank.
